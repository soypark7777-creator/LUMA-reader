# LUMA Heart 별자리 연결 확장 작업 아이디어

## 목표

`/heart`의 별자리 영역을 단순히 책 사이의 선을 보여주는 곳이 아니라, 사용자가 자신의 메모와 감정 기록을 통해 책 사이의 의미 연결을 탐색하는 “통찰 지도”로 확장한다.

## 현재 반영한 1차 방향

- 책 별자리 연결선을 누르면 연결 모달을 연다.
- 모달에서 두 책의 기본 정보, 감성적 연결, 통찰 질문을 보여준다.
- 메모 기반 연결 카드에서 두 메모를 선택해 딥다이브 방식의 크로스 인사이트를 생성한다.
- `/api/ai/connections`, `/api/ai/cross-insight`를 재사용해 기존 딥다이브 기능과 충돌하지 않게 연결한다.

## 다음 확장 아이디어

### 1. 연결 유형 분류

연결을 단순 유사도로만 보여주지 말고 다음 유형으로 나눈다.

- 같은 감정 반복
- 반대 감정 충돌
- 같은 질문의 변주
- 한 책의 답이 다른 책의 질문이 되는 관계
- 삶의 경험으로 이어지는 연결

### 2. 연결 카드 저장

사용자가 마음에 드는 연결 통찰을 저장할 수 있게 한다.

- `saved_insights` 또는 `memo_connections` 테이블 추가
- 연결된 두 메모 ID
- AI 통찰 텍스트
- 사용자가 덧붙인 내 해석
- 공개 여부

### 3. Lounge 공유

좋은 연결 통찰은 Lounge 또는 Social 카드로 보낼 수 있게 한다.

- “이 연결을 토론 카드로 보내기”
- 책 A, 책 B, 두 메모 요약, 토론 질문 1개 포함

### 4. 연결 필터

별자리 옆에 필터를 둔다.

- 감정별
- 책 상태별
- 최근 메모
- 강한 연결
- 서로 다른 장르 연결

### 5. 연결 깊이 단계

연결 모달에 단계형 탐색을 둔다.

1. 두 책이 공유하는 감정
2. 두 메모가 묻는 질문
3. 내 삶에 연결되는 지점
4. 독서모임에서 던질 질문
5. 다음에 읽을 책 추천

## 프론트엔드 연결 포인트

- `/heart` 별자리 패널
- 연결선 클릭
- 메모 연결 카드 클릭
- 책 기록 상세 모달 안 “연결 보기” 버튼

## 백엔드 연결 포인트

- `GET /api/ai/connections`
- `POST /api/ai/cross-insight`
- 추후 추가 후보: `POST /api/v2/insights/save`
- 추후 추가 후보: `GET /api/v2/insights/connections`
